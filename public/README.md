# Static assets

Drop the client's **official logo file here as `logo.png`** (unchanged, any
size — it renders at 40px height in the header and footer). Until that file
exists, the site shows a styled text logotype fallback automatically.

The live radiancerealtors.com blocks automated downloads, so the original
artwork must be added manually — export it from the client's site or brand
kit and commit it as `public/logo.png`.
